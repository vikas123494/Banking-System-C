# Banking Management System

A console-based Banking Management System developed in C to perform basic banking operations such as account creation, deposits, withdrawals, account management, and transaction tracking.

## Features

- Create a new bank account
- Generate unique account numbers
- Password-based account verification
- Deposit money
- Withdraw money
- Check account balance
- Display account details
- View transaction history
- Generate monthly transaction reports
- Modify account information
- Change account password
- Close an account
- Store account and transaction data using binary files

## Technologies Used

- C
- Structures
- Functions
- Pointers
- File Handling
- Binary File Operations
- String Handling
- Date and Time Handling
